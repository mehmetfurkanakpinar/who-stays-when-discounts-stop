# Who Stays When the Discounts Stop? And Why?
Discount campaigns are useful to attract customers in, but not everyone stays once the discount ends. This project aims to understand the customers who do stay.
## Repository structure
- `docs/`: problem framing, analysis plan, data audit, decision memo
- `sql/`: queries, in the order they are run
- `notebooks/`: analysis in Python
- `src/`: reusable metric functions and tests
- `reports/`: charts and final outputs
- `decision_log.md`: analysis decisions and why they were made
